🧙🏼 Upgrade from 6.x to 7.x

💴 Config

🍤 markdownItConfig: raw HTML disabled by default

This is a breaking change: in 7.x, MdEditor and MdPreview initialize markdown-it with html set to false instead of true:

diff Copy 
- html: true
+ html: false

After upgrading, raw HTML entered in Markdown, such as <u>, <img>, <br>, <iframe>, and <details>, is displayed as text. HTML in image captions is also displayed as text. The underline toolbar button and shortcut still insert <u>text</u>, which no longer renders an underline by default.

Existing HTML images, superscripts, and subscripts can be migrated to Markdown or plugin syntax such as ![description](url), ^superscript^, and ~subscript~. HTML generated by plugins for task lists, code blocks, math, and diagrams is unaffected by this option.

To preserve the raw HTML rendering behavior from 6.x, explicitly enable it before creating an editor or preview component:

ts Copy 
import { config } from 'md-editor-rt';

config({
  markdownItConfig(mdit) {
    mdit.set({ html: true });
  },
});

html controls raw HTML parsing and does not sanitize the final output. Use sanitize when the generated HTML needs sanitization. See markdownItConfig for more details.

📊 editorExtensions.echarts.parseOption

The default parser in 6.x executes JavaScript from code blocks, so functions can be used directly:

js Copy 
{
  tooltip: {
    formatter: (params) => `${params[0].value}`,
  },
}

Starting with 7.x, the default uses JSON5.parse and requires the top-level result to be a non-array object. Update the option to JSON5 data without functions, variable references, new, or call expressions:

json5 Copy 
{
  tooltip: {
    trigger: 'axis',
  },
  series: [
    {
      type: 'line',
      data: [1, 2, 3],
    },
  ],
}

If function syntax is still required, explicitly override parseOption(code, { editorId, element }):

ts Copy 
import { config } from 'md-editor-rt';

config({
  editorExtensions: {
    echarts: {
      parseOption(code) {
        return new Function(`return (${code})`)();
      },
    },
  },
});

Only use an executable parser with fully trusted Markdown. A custom parser must enforce its own input validation and security controls.

💴 Config

New:

ts Copy 
import { config, type CodeMirrorExtension, type Themes } from 'md-editor-rt';
import { type KeyBinding } from '@codemirror/view';

config({
  codeMirrorExtensions(
    extensions: Array<CodeMirrorExtension>,
    options: {
      editorId: string;
      theme: Themes;
      keyBindings: Array<KeyBinding>;
    }
  ): Array<CodeMirrorExtension> {
    return extensions;
  }
});
ts Copy 
interface CodeMirrorExtension {
  /**
   * Only used to provide developers with a basis for distinguishing between different extensions.
   */
  type: string;
  /**
   * Extensions of CodeMirror
   */
  extension: Extension | ((options: any) => Extension);
  /**
   * A Compartment wrapping the extension, which only exists for certain extensions,
   * provides the capability to update the extension.
   */
  compartment?: Compartment;
  options?: any;
}

Now you can accurately know which extension this is from extensions[i].type.

Past:

ts Copy 
import { config, type CodeMirrorExtension, type Themes } from 'md-editor-rt';
import { type KeyBinding } from '@codemirror/view';

config({
  codeMirrorExtensions(
    theme: Themes,
    extensions: Array<Extension>,
    keyBindings: Array<KeyBinding>,
    options: {
      editorId: string;
    }
  ): Array<Extension> {
    return extensions;
  }
});
